# Air Sign Studio

Real-time 2D sign language recognition and multilingual text-to-speech translator built with Python, MediaPipe, OpenCV, and a calibrated MLP + ExtraTrees ensemble.

## Features
- Dual Recognition Modes: Phrase Mode and ASL Alphabet A-Z Mode (TAB)
- 12-Language Real-Time Translation and Neural Voice Output (L)
- 15-Second Personal Hand Calibration Wizard (K)
- Custom Single-Sign Training (R)
- Multilingual Transcript Logging to transcript.txt (T)

## Installation and Run
pip install -r requirements.txt
py -3.12 global_air_sign.py

## Controls
TAB: Switch Phrase / A-Z | K: Personal Calibration | R: Train Custom Sign | L: Switch Language | S: Speak | SPACE: Space | BACKSPACE: Delete | C: Clear | M: Mute | T: Save Transcript | F: Fullscreen | Q: Quit
